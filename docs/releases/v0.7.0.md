TrailForge v0.7.0, an off-road vehicle prototype on a small custom C++20 engine (SDL3 + SDL GPU, Jolt Physics
`WheeledVehicleController`, Dear ImGui, own audio mixer on miniaudio). This stage turns the prototype into
something that starts like a game: an intro with music, a start menu over a live sunset scene, a real pause menu
over a blurred frame, and a Settings screen that is saved between runs. Physics and the vehicle are unchanged
from v0.6.0.

**Platforms:**

| Package | Status |
|---|---|
| `TrailForge-0.7.0-macos-arm64.zip` | macOS 27 on Apple Silicon. **Run and verified** (built for macOS 27.0). |
| `TrailForge-0.7.0-windows-x64.zip` | **UNTESTED ON REAL HARDWARE.** Built and headless-tested in GitHub Actions (MSVC, x64); the D3D12 / Vulkan rendering has never been run. |
| `TrailForge-0.7.0-linux-x64.tar.gz` | **UNTESTED ON REAL HARDWARE.** Built and headless-tested in GitHub Actions (gcc, Ubuntu); the app was only started on Mesa lavapipe (software Vulkan) under Xvfb. |

## What is new

- **Intro.** The TrailForge logo fades in over the intro music, then the start menu fades in while the music keeps
  playing. Any key, mouse click or gamepad button skips it (`--no-intro` skips it from the command line).
- **Start menu:** Start, Settings, Quit, over the live proving ground at sunset with a slow camera arc behind the
  vehicle. Start drives the current vehicle on the current proving ground; the music fades out over 3 s.
- **Pause menu (Esc / gamepad Start):** Resume, Reset vehicle, Settings, Quit to main menu, Quit game. It is a real
  pause: the physics does not tick (checked: 0 ticks and 0 m of movement in 1 s with the throttle held) while the
  frame keeps rendering, blurred and dimmed behind a minimal left-aligned menu.
- **Settings** (from both menus): graphics preset Low / Medium / High / Ultra, resolution scale, VSync, master /
  music / effects / UI volume, driver-aid defaults (ABS, traction control mode, diff locks, auto reverse) and a
  controls overview. Saved to `settings.cfg` in the user data folder (`trailforge --paths`) and loaded on start.
- **Menu input:** arrows / W S A D, Enter / Space, Esc / Backspace; mouse hover and click (click a setting's arrows
  to step it); gamepad D-pad or left stick, A to select, B to go back. Menu move / select / back / open / close
  sounds.
- **Sound in pause:** engine, tires and body sounds stop with the simulation; the day / night ambience keeps
  playing (it is not driven by the simulation); no music during play or pause.
- Font: Rajdhani (SIL Open Font License, Indian Type Foundry), rendered at the display's pixel density.
- The old Esc debug pause is now **P** (freeze without a menu; N steps one physics tick while frozen).

## How to open it

**macOS.** The app is **ad-hoc signed, not notarized**, so Gatekeeper blocks a plain double-click after downloading.

1. Unzip `TrailForge-0.7.0-macos-arm64.zip`.
2. Either right-click `TrailForge.app` → **Open** → **Open**, or remove the quarantine flag in Terminal:
   `xattr -dr com.apple.quarantine TrailForge.app`
3. Optional command-line options (run the binary inside the bundle):
   `TrailForge.app/Contents/MacOS/trailforge --help`

**Windows (untested on real hardware).** Unzip, keep the `assets` folder next to `trailforge.exe`, run it. The exe
is not code-signed, so SmartScreen may warn ("More info" → "Run anyway"). Needs a Direct3D 12 or Vulkan GPU driver.

**Linux (untested on real hardware).** `tar xzf TrailForge-0.7.0-linux-x64.tar.gz`, then
`./TrailForge-0.7.0-linux-x64/trailforge`. Needs a Vulkan driver (Mesa RADV / ANV / NVK or the NVIDIA driver).

## Known limitations

- Windows and Linux have never been run on real hardware; the Direct3D 12 path has not been run at all.
- Menu navigation with a gamepad has not been tested with a real controller (keyboard and mouse were tested
  through the real input path in scripted runs).
- Nobody has listened to the music, the menu sounds or the pause behavior by ear; levels were checked from the
  mixer's own read-outs.
- The menus were checked at one window size (2880x1800 pixels, 2x HiDPI); small windows and very wide screens were
  not looked at.
- The world keeps running behind the intro and the start menu (the vehicle idles at the start pad); Start resets
  the vehicle, so the engine start sound plays when the drive begins.
- macOS build not notarized; Windows build not code-signed.
- All v0.6.0 limitations still apply: grass and spray are render-only, ABS and TC are simplified logic, the ground
  is rigid (sand and mud are lower-friction surfaces only), and handling has not been judged by hand.
