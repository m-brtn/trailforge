TrailForge v0.29.0, an off-road vehicle prototype on a small custom C++20 engine (SDL3 + SDL GPU, Jolt Physics
`WheeledVehicleController`, Dear ImGui, own audio mixer on miniaudio). This is the first public release. It contains
only content with a licence that allows redistribution: the earlier private builds carried one level and two vehicle
bodies without such a licence, and they are removed.

**Platforms:**

| Package | Status |
|---|---|
| `TrailForge-0.29.0-macos-arm64.zip` | macOS 27 on Apple Silicon. **Run and verified** (built for macOS 27.0). |

There are no Windows or Linux packages for this release: CI is paused (GitHub Actions billing), so nothing was
built or tested on those platforms. Windows and Linux have never been run on real hardware in any release.

## What changed

- **Removed:** the Ironwall Stadium level and the IRONCLAD G and KESTREL M vehicles. Their source assets had an
  unknown or missing licence, so they cannot be published. The repository history was rewritten without them, and
  the earlier releases are not carried over to this repository.
- Everything else is as in v0.28.0: the proving ground with the mini handling track, Exploration Peaks, Suncoast
  Raceway, and three vehicles (SUV, electric SUV, Desert Patrol Buggy) with the v0.28.0 suspension, tire sets,
  drift scoring and landing sounds.

## Verification

- 105 automated tests pass in Debug and Release (94 in the headless build). The three removed tests loaded the
  removed level.
- Full regression scenario: 248 passed, 0 failed (Release, no audio). Bump strip scenario with the three shipped
  vehicles: 31 passed, 0 failed.
- A fresh clone of the public repository passes `git lfs fsck`; no file of the removed content is in any commit.

## How to open it

**macOS.** The app is **ad-hoc signed, not notarized**, so Gatekeeper blocks a plain double-click after downloading.

1. Unzip `TrailForge-0.29.0-macos-arm64.zip`.
2. Either right-click `TrailForge.app` → **Open** → **Open**, or remove the quarantine flag in Terminal:
   `xattr -dr com.apple.quarantine TrailForge.app`
3. Optional command-line options (run the binary inside the bundle):
   `TrailForge.app/Contents/MacOS/trailforge --help`

## Known limitations

- The level loader still supports static scene meshes (`"statics"` in level.json), but no shipped level uses them
  now, so that path is untested.
- The Desert Patrol Buggy (750 kg) can still flip with the throttle held or floored over a short, steep kicker or a
  step.
- No Windows or Linux packages for this release; those platforms have never been run on real hardware.
- macOS build not notarized.
- Earlier limitations still apply:
  - water has no physics; deep water and the map edge put the vehicle back on a road;
  - snow, sand, mud and gravel are rigid surfaces with lower grip;
  - grass, ground cover, spray and body mud are render-only;
  - ABS and TC are simplified logic;
  - tire temperatures are probably below track-day readings;
  - nobody has driven with a real gamepad;
  - buildings have no interiors.
