# TrailForge v0.31.0

A macOS / Apple Silicon release with the new TrailForge Expedition SUV and the changes since v0.29.0.
Version 0.30.0 was a local test package, not a public GitHub release.

## Changes

- A fourth selectable vehicle: Expedition, with an original olive/orange authored body, detailed exterior,
  scalar PBR materials, black wheelhouse liners that receive cosmetic mud, and corrected mirror face winding.
  Wheels, spare tires and suspension remain engine-generated. The vehicle uses its own 0.34-0.55 m suspension
  limits and a raise-only garage range, without a visual body offset.
- Changes already merged since v0.29.0 include water buoyancy and drag, revised tire and traction-control
  behavior, gear-change clutch control, improved terrain shading and clouds, local vehicle reflections,
  stylized trees, revised menus and body/landing sounds.
- iOS build support and menu touch input are in the source tree. iOS has only run in the Simulator;
  no real iPhone/iPad or real controller verification is claimed. This release ships no iOS package.

## Verification

- Debug and Release builds passed; all 113 CTest cases passed in both configurations. Debug required
  sequential retries of three timeout cases; the two dense-body wheel tests now have a 300 s limit.
- Full Release game regression: 248 passed, 0 failed. Expedition scenario: 10 passed, 0 failed,
  including automatic dirt deposition from wheel spray.
- Body conversion validates two garage configurations: 10.3 mm visual wheel-sweep clearance,
  35.7 mm collision clearance; 438 parts, seven collision hulls, two engine-generated spare seats.

## Controls

W/S throttle and brake, A/D steering, Space handbrake, R reset, C camera, Esc pause.
V cycles 2H/4H/4L on the combustion SUVs; H toggles headlights, M opens the map.
Choose Expedition in the vehicle menu. Gamepad: triggers for pedals, left stick for steering,
RB/R1 for camera, View/Create for reset, Menu/Options for pause.
See [controls](../controls.md) for the full mappings.

## Opening the app

Unzip `TrailForge-0.31.0-macos-arm64.zip`, then right-click `TrailForge.app` and choose Open.
The app is ad-hoc signed, not notarized. If needed, remove quarantine with
`xattr -dr com.apple.quarantine TrailForge.app`.

## Known limitations

- macOS / Apple Silicon / Metal is the verified release platform. There are no Windows or Linux packages:
  CI is paused. Windows and Linux have never been run on real hardware.
- Expedition's shorter compression travel preserves the authored stance. A held-throttle bump stress probe
  recorded 5 rollovers in 54 runs, on one-sided 0.40 m obstacles at 30-40 km/h. It is not rollover-proof.
- Body materials use scalar PBR settings; Blender noise nodes are not exported. Equipment masses are not
  simulated separately, and the dense authored body costs more rendering work than the procedural kit vehicles.
- Dirt is cosmetic; terrain remains rigid. Water forces do not simulate waves, flooding or engine intake.
