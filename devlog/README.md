# TrailForge devlog

One file per day: `devlog/YYYY-MM-DD.md` (local date). If there is no file for today, create it
from the template below. If it exists, append to it without rewriting other entries. The full agent conventions
are in `AGENTS.md` at the repository root.

Write in English, briefly and factually. Keep verified and unverified items clearly separate:
"Results" contains only what was actually run, with numbers.
Mark unfinished stages with the status **IN PROGRESS**.

## Template

```markdown
# Devlog — YYYY-MM-DD (weekday)

## Goal of the day

What we are doing today and why.

## Stages

- **HH:MM — stage name.** What was done, which decisions were made. Status, if the stage is not finished.

## Problems and solutions

- **Problem.** Cause. How it was solved (or what was tried, if unsolved).

## Results

Only what was actually verified: build, tests, measurements — with numbers.

## Limitations and open questions

What is unverified, known anomalies, simplifications.

## Next steps

1. …
```
